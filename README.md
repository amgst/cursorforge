# CursorForge

An interactive storefront for browsing and purchasing custom cursor designs through Shopify.

## Development

You need Node.js 22.12 or newer and npm.

```sh
npm install
npm run dev
```

Create a production build with:

```sh
npm run build
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
- Shopify Storefront API
